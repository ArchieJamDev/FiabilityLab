# FiabilityLab Test Dataset

`fiabilitylab_test_data.csv` (n = 450) — a single wide, purpose-built file
generated by
[`prepare_fiabilitylab_test_data.R`](../data-raw/prepare_fiabilitylab_test_data.R)
to exercise every reliability design in the FiabilityLab roadmap: dichotomous
parallel test forms, a hierarchical (2nd-order) Likert scale, multi-rater
nominal/ordinal/continuous agreement data, and a test-retest block with
realistic attrition.

This lives in `data/` and is registered under `datasets:` in
`jamovi/0000.yaml` — inside jamovi Desktop it shows up under **File → Open
→ Data Library → Fiability Lab** once the module is installed.

**Unlike AssumptionsLab's file, every column here is simulated from an
explicit latent-variable model** (item response theory for the dichotomous
forms, factor models for the Likert scales, a true-score-plus-rater-noise
model for agreement data) — there is no original external source. Every
block carries deliberate, documented data-quality flaws so the diagnostic
and interpretation engine has something real to catch, not just a clean
point estimate.

To regenerate it (identical output, fixed seed `20260908`):

```bash
Rscript data-raw/prepare_fiabilitylab_test_data.R
```

## Data-quality features baked in on purpose

- **A weak/noisy item** — `planning_05` (loading ≈ .30 by design). Item-total
  correlation (r.drop) comes out at .242 against .59–.66 for the other four
  Planning items — a real case for the "consider dropping this item" flag.
- **A forgotten reverse-code** — `reflection_04` is reverse-worded and
  deliberately left un-reverse-scored. Raw (un-reversed) alpha on the
  4-item Reflection subscale comes out **negative** (-0.067, `check.keys =
  FALSE`), with `reflection_04`'s r.drop at **-0.516** while the other three
  items are .28–.34 — psych's own `alpha()` flags it as "should be
  reversed" unprompted. This is the canonical realistic example for
  item-analysis diagnostics, not a synthetic edge case.
- **Skewed rater-category prevalence** (Low/Medium/High ≈ 65/25/10%,
  observed 274/119/57) — reproduces the Kappa/Gwet-AC1 "prevalence
  paradox": raw agreement between `rater1_category` and `rater4_category`
  (the least accurate rater) is 76.9% even though rater4's per-case
  accuracy was simulated at only 70%.
- **A biased rater** — `rater3_score` carries a deliberate +8-point mean
  shift (observed means: rater1 = 65.3, rater2 = 65.7, rater3 = 73.0) while
  still correlating strongly with the other two (r = .82–.89). This is the
  standard case for showing why *consistency*-type ICC stays high while
  *absolute-agreement*-type ICC drops for the same data. `rater3_severity`
  carries the equivalent ordinal-scale bias (+0.6 before rounding; observed
  means 2.83 / 2.91 / 3.41).
- **~2% MCAR missingness** in both knowledge-test forms, all 14
  Self-Regulation items, and the three continuous rater scores.
- **~30% test-retest attrition** — only 315 of 450 respondents have
  `mood_t2_*` data, a realistic dropout rate rather than a complete panel.
- **Parallel-forms correlation well below 1** — Form A/Form B total-score
  correlation = .619, and each form's own alpha (.63 / .65) is modest by
  design (two weak-discrimination items per form), so `internalConsistency`
  and any future parallel-forms/classification-consistency module have a
  realistic, not-inflated case to work with.

## Variables

### Identifiers & demographics

| Column | Type | Description |
|---|---|---|
| `id` | integer | Row identifier. Not an analysis variable. |
| `sex` | nominal (2 levels) | Female / Male (243 / 207). |
| `age` | integer | Continuous age, 18–70 (mean 40.2), sampled within `age_range`. |
| `age_range` | ordinal, 6 brackets | 18-25 / 26-35 / 36-45 / 46-55 / 56-65 / 66-70 (59/124/119/90/40/18). First-appearance order in the CSV is forced to this sequence so jamovi's ordinal auto-detection reads it correctly. |
| `education_level` | ordinal, 4 levels | Secondary / Technical / Undergraduate / Graduate (66/116/172/96); same first-appearance-order guarantee. Feeds a small positive effect into the knowledge-test ability (see below). |
| `marital_status` | nominal, 4 levels | Single / Married-Cohabiting / Divorced-Separated / Widowed (189/185/55/21). |
| `site` | nominal, 3 levels | Site A / Site B / Site C (192/162/96) — an institutional grouping variable, useful for future multi-site reliability-generalization demos. |

### Block — Dichotomous parallel test forms (`internalConsistency`, dichotomous/KR-20 path)

| Columns | Role |
|---|---|
| `knowledge_a01`–`knowledge_a10` | Form A, 10 binary (0/1) items. Item discrimination varies; items 8 and 10 are deliberately weak (r.drop ≈ .15). |
| `knowledge_b01`–`knowledge_b10` | Form B, parallel form on the same latent ability (independent item parameters, independent form-specific noise). |

**Currently finds:** raw alpha .63 (Form A) / .65 (Form B), KR-20-equivalent
on binary data; Form A–Form B total-score correlation .62 — a realistic
parallel-forms case, not r = 1.

### Block — Hierarchical Likert scale: Academic Self-Regulation (`internalConsistency`, classical + future Advanced/SEM tab)

| Columns | Role |
|---|---|
| `planning_01`–`planning_05` | Planning subscale, 1–5 Likert. `planning_05` is a weak item. |
| `monitoring_01`–`monitoring_05` | Monitoring subscale, 1–5 Likert. |
| `reflection_01`–`reflection_04` | Reflection subscale, 1–5 Likert. `reflection_04` is reverse-worded and NOT reverse-scored. |

All three subscales load on one simulated second-order "Self-Regulation"
factor (loadings .65–.75), which is what will make this block useful for
the future SEM-based Advanced tab (AVE, CR, H coefficient, 2nd-order omega,
HTMT) once that ships.

**Currently finds:** Planning alpha .77 (item 5's r.drop = .24 against
.59–.66 for the rest), Monitoring alpha .87 (no problem items), Reflection
raw alpha **-0.07** un-reversed (item 4's r.drop = -.52) — the intended
"forgotten reverse-code" pathology.

### Block — Multi-rater agreement (`interRater`)

| Columns | Level | Role |
|---|---|---|
| `rater1_category`–`rater4_category` | Nominal, 3 levels (Low/Medium/High) | Cohen's/Fleiss' Kappa, Gwet's AC1/AC2. Prevalence skewed ~65/25/10%; rater4 is the least accurate (simulated 70% per-case accuracy). |
| `rater1_severity`–`rater3_severity` | Ordinal, 1–5 | Weighted Kappa, Krippendorff's Alpha (ordinal). `rater3_severity` carries a +0.6 systematic bias. |
| `rater1_score`–`rater3_score` | Continuous, 0–100 | ICC (all forms), Krippendorff's Alpha (interval), Kendall's W. `rater3_score` carries a +8-point mean bias (r = .82–.89 with the other two despite the shift) — the standard case for contrasting consistency vs. absolute-agreement ICC. ~2% MCAR missingness. |

### Block — Test-retest: Mood State scale (future `temporalStability` module)

| Columns | Role |
|---|---|
| `mood_t1_01`–`mood_t1_06` | Time 1, 6-item unidimensional 1–5 Likert scale. |
| `mood_t2_01`–`mood_t2_06` | Time 2 (~2-week interval), same items. Only 315/450 respondents have Time 2 data (~30% attrition). |

**Currently finds:** sum-score test-retest correlation .63 (latent stability
was simulated at .72; the drop reflects realistic attenuation from
item-level measurement error, not a data error) — a plausible, not
inflated, retest coefficient.
